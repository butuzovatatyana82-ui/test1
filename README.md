# Okunek Music 3.0

Личный музыкальный плеер для Windows: библиотека, поиск по нескольким источникам, карточки исполнителей,
тексты песен, плейлисты. Фильтр «только оригиналы» отсекает ремиксы, мэшапы, каверы, лайвы и ускоренные версии.

## Запуск из исходников
Нужен Python 3.10+ (64-bit). Дальше — двойной щелчок по `run.bat` (или `python main.py`).
При первом запуске программа сама поставит `python-vlc`, `mutagen`, `pillow`, скачает yt-dlp и портативный VLC
(если VLC не установлен), а затем в фоне — Deno (JS-движок, без которого YouTube часто не отдаёт звук).
Всё лежит в `%APPDATA%\OkunekMusic`, права администратора не нужны.

## Сборка установщика
1. Установите [Inno Setup 6](https://jrsoftware.org/isinfo.php).
2. Запустите `build.bat` → получится `installer_out\OkunekMusic-<версия>-Setup.exe`.
   Установка идёт в профиль пользователя; новая версия ставится поверх старой, библиотека и плейлисты сохраняются.

## Обновления
- **yt-dlp** обновляется сам (раз в 12 часов, в фоне) — YouTube ломает старые версии регулярно. Применяется при следующем запуске.
- **Сама программа**: создайте репозиторий на GitHub, впишите `UPDATE_REPO = "логин/репозиторий"` в `okunek/config.py`.
  Чтобы выпустить версию: поднимите `VERSION`, затем `git tag v3.0.1 && git push --tags` — `.github/workflows/release.yml`
  соберёт установщик и выложит его в Releases. Установленные копии при запуске предложат обновиться
  (тихая установка поверх, плеер перезапустится сам). Проверить вручную: ⚙ → «Проверить обновления программы».

## Источники
Каталог (Deezer — официальные релизы), YouTube Music, YouTube, SoundCloud, Bilibili, Niconico и «Все».
Вставьте в поиск ссылку — подойдёт любой сайт, который знает yt-dlp (Bandcamp, Mixcloud, VK, плейлисты и т. д.).
Треки из каталога играют через автоподбор оригинальной записи (Topic-канал/официальный, длительность ±секунды),
при сбое — через запасной источник.

## Карточка исполнителя
Клик по имени исполнителя (в списке или внизу в плеере): фото, число фанатов, «Популярное», «Все песни» (вся
дискография без ремиксов и дублей), «Альбомы» (клик — треки альбома). Среднее число прослушиваний — это средние
просмотры YouTube у топ-треков исполнителя; ключ Last.fm (⚙, бесплатный) добавляет число слушателей.
